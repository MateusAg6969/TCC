✅ 1. PRÉ-REQUISITOS
═══════════════════════════════════════════════════════════════════════════════════

Antes de começar, certifique-se de que:

□ MongoDB está instalado e rodando
  - Windows: Use MongoDB Compass ou comando: mongod
  - Verifique: mongodb://localhost:27017

□ Servidor Express está rodando
  - Terminal: cd C:\TCC\if-rede-backend
  - Comando: npm run dev
  - Resultado esperado: "Servidor iniciado na porta 3000"

□ Tem curl instalado (ou usará Postman)
  - Windows: curl já vem com Windows 10+
  - Alternativa: Postman (https://www.postman.com)

□ Variáveis de ambiente (.env) configuradas
  - Verifique: PORT=3000
  - Verifique: MONGODB_URI=mongodb://localhost:27017

🐛 6. TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════════

PROBLEMA: "Connection refused"
SOLUÇÃO:
  1. Verifique se servidor está rodando: npm run dev
  2. Verifique porta: netstat -ano | findstr :3000
  3. Reinicie o servidor

PROBLEMA: "MongoDB connection error"
SOLUÇÃO:
  1. Verifique se MongoDB está rodando: mongod
  2. Verifique variável MONGODB_URI no .env
  3. Conecte com: mongo mongodb://localhost:27017

PROBLEMA: "Invalid token"
SOLUÇÃO:
  1. Verifique se token está correto
  2. Verifique se está usando Bearer corretamente
  3. Gere novo token fazendo login novamente

PROBLEMA: "User not found"
SOLUÇÃO:
  1. Verifique se o usuário foi registrado
  2. Copie o ID correto do registro
  3. Registre novo usuário se necessário

PROBLEMA: "Email already exists"
SOLUÇÃO:
  1. Use email diferente (ex: joao2@test.ifrede.com)
  2. Ou delete usuários antigos do banco

PROBLEMA: Erro 400 - Validação
SOLUÇÃO:
  1. Verifique campos obrigatórios
  2. Verifique formatos esperados
  3. Leia mensagem de erro
