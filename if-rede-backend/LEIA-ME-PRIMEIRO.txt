🚀 COMO COMEÇAR AGORA
───────────────────────────────────────────────────────────────────────────────

1. INICIE O MONGODB:
   $ mongod

2. INICIE O SERVIDOR:
   $ cd if-rede-backend
   $ npm run dev

3. TESTE A API:
   $ curl http://localhost:3000/health

4. REGISTRE UM USUÁRIO:
   $ curl -X POST http://localhost:3000/auth/register \
     -H "Content-Type: application/json" \
     -d '{
       "nome": "João Silva",
       "email": "joao@ifrede.com",
       "matricula": "2024001",
       "senha": "senha123456"
     }'

   Guarde o accessToken retornado!

5. USE O TOKEN:
   $ TOKEN="seu_token_aqui"
   $ curl http://localhost:3000/perfil/meu-perfil \
     -H "Authorization: Bearer $TOKEN"

📞 RESOLUÇÃO DE PROBLEMAS COMUNS
───────────────────────────────────────────────────────────────────────────────

❌ "Connection refused"
   ✅ Solução: Inicie MongoDB com: mongod

❌ "Token inválido"
   ✅ Solução: Use o accessToken, não refreshToken
   ✅ Solução: Formato correto: "Authorization: Bearer <token>"

❌ "Usuário não encontrado"
   ✅ Solução: Verifique o ID do usuário
   ✅ Solução: Verifique se o usuário foi criado

❌ "Campos obrigatórios"
   ✅ Solução: Envie: nome, email, matricula, senha
   ✅ Solução: Consulte SISTEMA-PERFIS-API.md

❌ "MongoDB não está rodando"
   ✅ Solução: Execute: mongod
   ✅ Solução: Verifique se está em http://localhost:27017
