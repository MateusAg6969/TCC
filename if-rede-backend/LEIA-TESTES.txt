🔧 PRÉ-REQUISITOS
═══════════════════════════════════════════════════════════════════════════════════

Antes de rodar os testes, certifique-se:

□ MongoDB está rodando
  Comando: mongod

  Comando: npm run dev

  MONGODB_URI=mongodb://localhost:27017
  JWT_SECRET=sua_secret_aqui

□ Node.js v14+ instalado
  Verificar: node --version

□ curl ou Postman instalado
  Verificar: curl --version (ou abra Postman)

💡 DICAS
═══════════════════════════════════════════════════════════════════════════════════

1. Use curl com -s para saída limpa:
   curl -s http://localhost:3000/health | jq '.'

2. Salve os tokens em variáveis:
   TOKEN="seu_token_aqui"
   curl http://localhost:3000/perfil/meu-perfil -H "Authorization: Bearer $TOKEN"

3. Use jq para formatar JSON:
   curl ... | jq '.' (com cores)
   curl ... | jq '.data' (apenas data)

4. Verifique o banco:
   mongo mongodb://localhost:27017
   use if-rede
   db.usuarios.find()

5. Limpe o banco entre testes:
   db.usuarios.deleteMany({})
   db.privacidades.deleteMany({})
   ... etc
