🔐 SEGURANÇA IMPLEMENTADA
═══════════════════════════════════════════════════════════════════════════════

✅ AUTENTICAÇÃO JWT
   └─ Header: Authorization: Bearer <TOKEN>
   └─ Validação em authMiddleware
   └─ Payload extraído: { sub, email, vinculo, mod_voluntario }

✅ AUTORIZAÇÃO (Ownership)
   └─ Usuário só acessa/modifica seus próprios dados
   └─ Verificação: String(usuarioId) === String(req.usuario.id)
   └─ Status 403 Forbidden se não é dono

✅ VALIDAÇÕES DE INPUT
   └─ ObjectId válido
   └─ Campos obrigatórios
   └─ Tamanho máximo de strings
   └─ Formato de email (regex)
   └─ Enums validados
   └─ Prevenção de auto-amizade
   └─ Detecção de duplicatas

✅ LOGS DE AUDITORIA
   └─ solicitacao-amizade-enviada
   └─ solicitacao-amizade-aceita
   └─ solicitacao-amizade-recusada
   └─ amizade-desfeita
   └─ perfil-atualizado
   └─ customizacao-atualizada
   └─ IP do cliente registrado

✅ TRATAMENTO DE ERROS
   └─ Try/catch em cada função
   └─ Mensagens específicas por status
   └─ Erros não previstos → middleware global
   └─ Status HTTP semânticos


📊 ENDPOINTS IMPLEMENTADOS
═══════════════════════════════════════════════════════════════════════════════

AMIZADES (7 ENDPOINTS)
──────────────────────────────────────────────────────────────────────────────

   POST /api/amizades/solicitar
   ├─ Autenticação: ✅ JWT obrigatório
   ├─ Body: { "amigoId": "507f..." }
   ├─ Status: 201 Created | 400 | 404 | 409
   └─ Auditoria: Log de "solicitacao-amizade-enviada"

   POST /api/amizades/:id/aceitar
   ├─ Autenticação: ✅ JWT obrigatório
   ├─ Validação: Usuario é o destinatário
   ├─ Status: 200 OK | 400 | 403 | 404 | 409
   └─ Auditoria: Log de "solicitacao-amizade-aceita"

   POST /api/amizades/:id/recusar
   ├─ Autenticação: ✅ JWT obrigatório
   ├─ Body: { "motivo": "..." } (opcional)
   ├─ Status: 200 OK | 400 | 403 | 404 | 409
   └─ Auditoria: Log de "solicitacao-amizade-recusada"

   DELETE /api/amizades/:id
   ├─ Autenticação: ✅ JWT obrigatório
   ├─ Validação: Qualquer um dos amigos pode desfazer
   ├─ Status: 200 OK | 400 | 403 | 404 | 409
   └─ Auditoria: Log de "amizade-desfeita"

   GET /api/amizades/meus-amigos?page=1&limit=20
   ├─ Autenticação: ✅ JWT obrigatório
   ├─ Paginação: page, limit (máximo 100)
   ├─ Status: 200 OK | 500
   └─ Retorna: Array de amigos + total + páginas

   GET /api/amizades/solicitacoes?page=1&limit=20
   ├─ Autenticação: ✅ JWT obrigatório
   ├─ Filtro: Apenas status="pendente"
   ├─ Status: 200 OK | 500
   └─ Retorna: Array de solicitações recebidas

   GET /api/amizades/verificar/:amigoId
   ├─ Autenticação: ✅ JWT obrigatório
   ├─ Retorna: { status, soAmigos, temSolicitacaoPendente, quemEnviou }
   ├─ Status: 200 OK | 400 | 500
   └─ Uso: Botão dinâmico no frontend


USUÁRIOS (4 ENDPOINTS)
──────────────────────────────────────────────────────────────────────────────

   GET /api/usuarios/:id
   ├─ Autenticação: ❌ Opcional (qualquer um vê)
   ├─ Privacidade: Respeita nível de privacidade do usuário
   ├─ Status: 200 OK | 400 | 404
   └─ Retorna: Perfil público + stats

   GET /api/usuarios/me
   ├─ Autenticação: ✅ JWT obrigatório
   ├─ Status: 200 OK | 404 | 500
   └─ Retorna: Perfil completo + email + customizacao + stats + conexoes

   PUT /api/usuarios/me
   ├─ Autenticação: ✅ JWT obrigatório
   ├─ Body: { "nome", "bio", "email", "privacidade" }
   ├─ Status: 200 OK | 400 | 404 | 409 | 500
   ├─ Validações: Email único, tamanho máximo
   └─ Auditoria: Log de "perfil-atualizado"

   PUT /api/usuarios/me/customizacao
   ├─ Autenticação: ✅ JWT obrigatório
   ├─ Body: { "tema", "cores", "foto_perfil_url", "banner_url" }
   ├─ Status: 200 OK | 400 | 404 | 500
   ├─ Validações: Cores em #RRGGBB, URLs com http
   └─ Auditoria: Log de "customizacao-atualizada"


💾 MODELO DE DADOS (AMIZADE)
═══════════════════════════════════════════════════════════════════════════════

Documento Amizade:
{
  _id: ObjectId,
  usuarioId: ObjectId,              // Quem vai RECEBER
  amigoId: ObjectId,                // Quem ENVIOU
  status: 'pendente|aceito|recusado',
  dataSolicitacao: Date,            // Imutável
  dataResposta: Date,               // Preenchida ao responder
  motivoRecusa: String,             // Opcional
  tipo_relacao: 'amigo_comum|melhor_amigo|colega',
  createdAt: Date,
  updatedAt: Date
}

Índices:
  1. Unique Composto: {usuarioId, amigoId, status}
  2. Lista Amigos: {usuarioId, status, dataSolicitacao}
  3. Solicitações Recebidas: {usuarioId, status, dataSolicitacao}
  4. Solicitações Enviadas: {amigoId, status, dataSolicitacao}
  5. TTL Recusas: Limpeza automática após 90 dias

🚀 COMO USAR
═══════════════════════════════════════════════════════════════════════════════

1. INICIAR O BACKEND
   $ cd if-rede-backend
   $ npm install
   $ npm run dev

2. FAZER REQUISIÇÕES COM cURL
   Veja exemplos em exemplos-amizades-usuarios.js

3. INTEGRAR NO FRONTEND
   ```javascript
   const token = localStorage.getItem('authToken');
   
   async function enviarSolicitacao(amigoId) {
     const response = await fetch('/api/amizades/solicitar', {
       method: 'POST',
       headers: {
         'Content-Type': 'application/json',
         'Authorization': `Bearer ${token}`
       },
       body: JSON.stringify({ amigoId })
     });
     return await response.json();
   }
   ```

4. VER DOCUMENTAÇÃO COMPLETA
   $ cat IMPLEMENTACAO-AMIZADES-E-USUARIOS.md
