🎯 TESTE MANUAL COM CURL (Cópia e Cola)
───────────────────────────────────────────────────────────────────────────────

# 1. HEALTH CHECK
curl http://localhost:3000/health

# 2. REGISTRAR USUÁRIO
curl -X POST http://localhost:3000/auth/register ^
  -H "Content-Type: application/json" ^
  -d "{\"nome\":\"João\",\"email\":\"joao@test.com\",\"matricula\":\"2024001\",\"senha\":\"Senha@123456\",\"status_vinculo\":\"estudante\"}"

# Salve: TOKEN e USUARIO_ID da resposta

# 3. OBTER MEU PERFIL
curl http://localhost:3000/perfil/meu-perfil ^
  -H "Authorization: Bearer TOKEN"

# 4. ATUALIZAR PERFIL
curl -X PUT http://localhost:3000/perfil/atualizar ^
  -H "Authorization: Bearer TOKEN" ^
  -H "Content-Type: application/json" ^
  -d "{\"nome\":\"João Silva\",\"bio\":\"Dev Full Stack\"}"

# 5. CUSTOMIZAR APARÊNCIA
curl -X PUT http://localhost:3000/perfil/atualizar-customizacao ^
  -H "Authorization: Bearer TOKEN" ^
  -H "Content-Type: application/json" ^

⚠️ POSSÍVEIS ERROS E SOLUÇÕES
───────────────────────────────────────────────────────────────────────────────

"Connection refused"
  → MongoDB ou servidor não estão rodando
  → Solução: mongod && npm run dev

"Invalid token"
  → Token está incorreto ou expirado
  → Solução: Registre novo usuário e copie token correto

"Email already exists"
  → Email já foi usado em teste anterior
  → Solução: Use email diferente (ex: joao2@test.com)

"User not found"
  → ID do usuário está incorreto
  → Solução: Copie o ID exato da resposta de registro

"400 Bad Request"
  → Campos obrigatórios faltando
  → Solução: Verifique a estrutura do JSON

Mais soluções em: GUIA-TESTES-COMPLETO.txt → Seção 6
